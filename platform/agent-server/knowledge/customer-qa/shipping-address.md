# Shipping Address Changes

## Before shipment

An address change may be possible before an order is fulfilled. Contact support
with the order number and the corrected address; do not assume that changing a
profile address changes an existing order.

## After shipment

Once a parcel is with the carrier, delivery-change options depend on the
carrier, destination, and shipment status. The customer may need to use the
carrier's delivery-management tools or request a support handoff. Never claim
that an address change is guaranteed after dispatch.

Source: https://www.ups.com/us/en/support/change-delivery-options.page
