# Order Cancellation

## Cancellation window

An order may be cancellable while it is still being processed. Once fulfillment
or shipment has started, cancellation may no longer be possible; the customer
may need to use the return process instead.

## Required information

Ask for the order number and verify the request before promising cancellation.
If cancellation cannot be completed, explain the next supported option and
route the case to support when an account lookup is required.

Source: https://help.shopify.com/en/manual/orders/manage-orders/cancel-orders
