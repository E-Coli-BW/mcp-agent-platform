# Package tracking status guidance

Source: USPS, Where is my package? Tracking Status Help.

“Delivered” means the package has a recorded delivery date, time, and location.
If it cannot be found, the customer should check safer locations and tracking
details before contacting support.

“Out for Delivery” means the package has been prepared for delivery and is
expected that day. If it has not arrived after one full postal business day,
the customer can use the tracking number to submit a service request.

“Shipping Label Created” or “Pre-Shipment” means a label exists but USPS has
not received the package. Questions about that status should usually go to the
shipper.

“Insufficient Address” or “No Such Number” means the package cannot be
delivered because the address is incomplete or incorrect and it is being
returned to the sender. The sender should verify the complete address when the
package is returned.

These are general USPS explanations, not live tracking results for a specific
order. A support agent must not infer the current status of an order without a
tracking lookup.
