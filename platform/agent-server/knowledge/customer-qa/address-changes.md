# Change of address guidance

Source: USPS, Change of Address - The Basics, and Standard Forward Mail.

Mail is forwarded to a new address only after a USPS Change of Address request
is submitted. A request can be submitted online or in person. USPS says an
online request requires identity verification and a small authentication fee;
customers should use the official USPS site rather than links from unsolicited
messages.

A change-of-address request changes the mailing address with USPS. It does not
update a private merchant's account, an order's shipping address, or any other
business record. A customer asking to change a merchant order address needs the
merchant's authenticated order workflow or human support.
