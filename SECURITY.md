# Security Policy

Please do not report security vulnerabilities in a public issue. Contact the
maintainers privately with a description, reproduction steps, affected version,
and suggested mitigation. Do not include real credentials or customer data.

The local Docker code executor is a demonstration component. Review its
resource limits and deployment assumptions before using it with untrusted code.
MCP tools that perform external side effects require application-level
authentication, authorization, validation, idempotency, and approval controls.
